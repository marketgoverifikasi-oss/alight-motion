
## 🚀 Deploy ke Vercel

1. Login [vercel.com](https://vercel.com)
2. Import project / upload folder
3. Klik **Deploy**

File `vercel.json` sudah otomatis terkonfigurasi.

## ⚙️ Fitur

| Mode | Fungsi |
|------|--------|
| **Manual** | User kirim magic link ke email sendiri → verifikasi |
| **Bulk** | Sistem generate 5 email temp (Gmail) → auto premium |

## 📞 Kontak

Hubungi admin via tombol WhatsApp di website.
